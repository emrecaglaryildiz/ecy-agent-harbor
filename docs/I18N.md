# English / Turkish localization

- `static/i18n.js` owns browser language selection, the TR/EN control, and UI-only text localization.
- `static/locales/en.json` maps canonical Turkish application labels/messages to English. Unknown user text is never sent to a translation service.
- A saved `tr` or `en` selection wins. Otherwise `navigator.language` beginning with `tr` selects Turkish; every other browser language selects English. Invalid stored values are ignored.
- The ECY Agent Harbor name and SVG logo remain unchanged in both languages. The language button sits beside the theme button; another control is available during sign-in. Switching language does not reload the page or clear drafts.
- User/model content is excluded: prompt fields, rendered Markdown, evidence lines, task titles, custom names, custom templates and project instructions. Built-in template prompts may be localized when explicitly applied; existing user-edited prompts are retained.
- Dates/numbers use the chosen UI locale. API requests carry `Accept-Language`. Legacy API clients without that header keep Turkish errors.
- Exports use a `lang=tr|en` parameter for headings/metadata only; original outputs are unchanged. New tasks and schedules store their notification language.
- Language changes do not make model calls, translate evidence remotely, or change provider instructions.

Türkçe: Dil tercihi tarayıcıda saklanır. İlk dil tarayıcıya göre belirlenir; kullanıcı içeriği çevrilmez. Menü çevirileri yerel katalogdadır. Yeni metin eklerken katalog ve dil testlerini güncelle.
