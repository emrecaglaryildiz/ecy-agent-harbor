# Kurumsal gelişim planı / Enterprise roadmap

## Mevcut sınır / Current boundary

ECY Agent Harbor bugün tek çalışma alanlı bir uygulamadır. Projeler çalışma alanı içinde paylaşılır; mevcut admin/operator/viewer rolleri proje veya kuruluş izolasyonu değildir. Birden çok güvenilmeyen müşteriye hizmet veren bir SaaS olarak yayımlanmamalıdır. SQLite ve süreç içi çalışanlar henüz çok sunuculu yüksek erişilebilirlik sunmaz. / Harbor currently provides one shared workspace. Existing roles do not establish project or tenant isolation. It is not a multi-tenant SaaS; SQLite and in-process workers do not provide multi-server high availability.

İlk sekiz fazın durumu [NEXT-PHASES.md](NEXT-PHASES.md) içinde izlenir. Aşağıdaki fazlar için yalnızca açıkça belirtilen parçalar teslim edilmiştir. / The first eight phases are tracked separately; only explicitly marked parts below have shipped.

## Faz 9: hazır olma kontrolleri / Phase 9 probes

- `GET /api/health/live`: HTTP sürecinin yanıt verdiğini bildirir; `200 {"ok":true}`.
- `GET /api/health/ready`: kapanma işareti yoksa ve mevcut veritabanındaki temel görev tabloları okunabiliyorsa `200 {"ok":true}`, aksi halde `503 {"ok":false}`. Eksik veritabanı oluşturmaz; sorgular salt okunurdur, kilit bekleme süresi 250 ms ile sınırlıdır.
- İki uç da kimlik bilgisi gerektirmez; yalnızca boolean yanıt verir. Host doğrulaması korunur. Eski `/api/health` uyumluluk için durur. Docker sağlık kontrolü artık readiness ucunu kullanır.
- Bu kontrol sağlayıcı, MCP, internet, disk kapasitesi veya işleyici thread'lerinin sağlıklı olduğunu iddia etmez. Sağlayıcıya ücretli test isteği göndermez, otomatik yeniden başlatma veya iş tekrarı yapmaz. Dış izleme servisinin bu adreslere erişimini işletmeci yapılandırır.

`/api/health/live` reports HTTP liveness. `/api/health/ready` reads the existing database in read-only mode and checks core tables and shutdown state, returning only `ok` with HTTP 200/503. Missing databases are never created; lock waits are bounded at 250 ms. Host validation remains in force; Docker now uses readiness. These probes do not certify providers, MCP servers, network access, disk capacity or worker thread health, perform paid requests, restart processes or replay jobs.

## Teslim disiplini / Delivery discipline

Her faz küçük sürümlere bölünür. Test, veri geçişi, geri dönüş ve yetki sınırları doğrulanmadan kurumsal kabul verilmez. Finansal kullanım bilgi amaçlı izlenir; kullanıcı isteğine uygun olarak harcama kotası eklenmez. Eşzamanlılık ve dosya kaynak korumaları maliyet kotası değildir. / Each phase ships in small releases with explicit tests, migrations, rollback and access boundaries. Spending remains informational without financial quotas; concurrency and file safety controls protect resources.

Kurumsal güvenlik bir garanti veya sertifika iddiası değildir. Gerçek dağıtımın DNS/HTTPS, ağ, yedekleme, erişim ve olay müdahalesi sorumlulukları ayrıca doğrulanmalıdır. / This roadmap makes no security certification or invulnerability claim; deployment-specific DNS/TLS, network, recovery, access and incident response need separate acceptance.
